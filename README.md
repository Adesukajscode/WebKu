# AI Tools Web

Koleksi tools bertenaga AI: downloader, konverter, utilitas, hand tracker, night vision, dan banyak lagi.

## Fitur
- 🤖 Floating AI Chat (Groq · GPT-OSS 120B)
- 📥 Downloader YouTube & TikTok
- 🖼️ Image, Audio, File Converter
- 🌙 Night Vision & Thermal
- 🤚 Hand Tracker realtime
- 📞 Hubungi Teman (WhatsApp)

## Stack
- React 18 + Vite
- Tailwind CSS v4
- Framer Motion
- MediaPipe Tasks Vision
- FFmpeg.wasm
- Cloudflare Pages + Workers
